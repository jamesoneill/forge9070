Quick start

Build, inspect, explore.

The repository retains its original URL to preserve links and existing scripts. nextora, forgeai, forge-engine and forge9070 invoke the same native engine. Legacy Strata commands and profiles require migration.

git clone https://github.com/jamesoneill/forge9070.git cd forge9070 cargo build --release --locked -p forge-engine ./target/release/nextora serve --help

On Windows, use .\target\release\nextora.exe. See the native engine guide for drivers, settings and supported model formats.
