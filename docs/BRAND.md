# Nextora visual identity

**Nextora** is the public identity of the Rust local AI inference engine.
The angular hexagonal orbit and linked **N** represent hardware-aware routing,
memory flow, and local computation. The identity deliberately avoids vendor
branding and does not imply every GPU or model is supported.

## Artwork

- [Nextora vector logo](assets/nextora-logo.svg) — the canonical project mark.
- [Artwork licence](assets/LICENSE-MIT) — applicable terms for original artwork.

The colour system uses **orbit violet** `#B99AFF`, **signal teal**
`#6EE7D4`, **deep indigo** `#0C1018`, and **warm white** `#F5F6F8`.
Preserve the logo geometry, use sufficient contrast, and leave clear space.
Historical artwork remains accessible in Git history, not the active brand.

See [migration](RENAME.md) for current executable names. Technical capability
and performance claims must reference [validation](../VALIDATION.md).
