# Code of conduct

Forge9070 welcomes useful technical contributions, questions and reproducible
reports. Treat participants with respect, including when disagreeing about
implementation choices, model behavior or project priorities.

## Expected behavior

- Discuss the code and evidence. Explain disagreements without attacking people.
- Make room for different levels of experience and accessibility needs.
- Give credit for upstream work and correct mistakes openly.
- Keep issues and pull requests focused on work relevant to the project.

Harassment, threats, discriminatory abuse, deliberate disruption, sexual
harassment and publishing another person's private information are unacceptable.
Do not use project discussions to target individuals or solicit harmful conduct.

## Scope and response

This policy applies to repository issues, pull requests and other project-managed
spaces. @jamesoneill maintains these spaces and may edit or remove disruptive
content, close discussions, or restrict participation. Responses should reflect
the conduct and its impact; repeated or severe abuse may result in removal.

Report concerns to @jamesoneill through an existing private channel where one is
available. If you need a private contact route, make a minimal request without
publishing personal details or repeating abusive material. Use GitHub's reporting
tools for platform abuse. Do not post private reports publicly.

Security vulnerabilities follow [SECURITY.md](SECURITY.md). Technical criticism
and good-faith bug reports are welcome; this policy does not require agreement
with maintainers or other contributors.
